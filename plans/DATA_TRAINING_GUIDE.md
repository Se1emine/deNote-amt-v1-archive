# Данные, разметка, обучение и Demucs

Простыми словами: откуда брать данные, зачем разметка, как учить модель и прав ли подход «учить на выходе Demucs».

---

## Да: данные — самое важное

Нейросеть учится только на парах:

```text
звук  +  «какие ноты когда звучали» (разметка)
```

Без разметки (только mp3/wav) **обучать нельзя** — модели не на чем сверяться.  
Архитектура и код важны, но **качество и близость данных к реальному использованию** решают сильнее.

---

## Где взять разметку нот?

Разметка = список нот: **pitch + start + end** (иногда velocity).

| Источник | Откуда разметка | Аудио | Насколько «своими руками» |
|----------|-----------------|-------|---------------------------|
| **GuitarSet** | Уже есть (JAMS) | Реальная гитара | Скачал → положил |
| **MAPS / MAESTRO** | Уже есть (MIDI) | Фортепиано | Скачал |
| **Synth** | Из MIDI «идеально» | Сам рендеришь FluidSynth | MIDI + SoundFont |
| **Свои песни** | **Нет** (или сам/руками/платно) | Есть | Долго и дорого |
| **YouTube / Spotify** | **Нет** | Есть | Без лейблов не train |

### Готовые датасеты (куда идти)

1. **GuitarSet** (рекомендуется для гитары)
   - Поиск: «GuitarSet ISMIR» / Zenodo GuitarSet  
   - ~360 коротких записей, 6 игроков  
   - Есть **mix** и hexaphonic, разметка нот по времени  
   - Лицензия открытая (CC BY)

2. **Синтетика**
   - MIDI: [Lakh MIDI Dataset](https://colinraffel.com/projects/lmd/)  
   - Рендер: FluidSynth + SoundFont  
   - Разметка = сам MIDI (бесплатно и сколько угодно)

3. **Фортепиано (если нужно «ещё данных»)**
   - MAESTRO, MAPS — отличные лейблы, но это **не гитара и не вокал**

4. **Вокал**
   - Vocadito, MIR-1K и похожие (melody/notes annotations)  
   - Не GuitarSet

**Свои треки без MIDI:**  
можно только если сделаешь разметку сам (MIDI в DAW, Basic Pitch + ручная правка). Для старта обычно **не** с этого начинают.

## Прав ли подход «учить на выходе Demucs»?

### Частично да

В deNote цепочка такая:

```text
песня → Demucs (guitar / vocals stem) → модель нот
```

На инференсе модель видит **не студийный clean guitar**, а **stem после separation**: артефакты, bleed, приглушённые частоты.

Если учить **только** на идеальном GuitarSet, а в бою кормить Demucs-stem — будет **domain gap** (хуже, чем на тестовом GuitarSet).

### Но не «только Demucs с песен»

| Идея | Проблема |
|------|----------|
| Взял песни → прогнал Demucs → учим | **Нет разметки нот** на этих stem’ах |
| Учить только на «грязных» stem’ах с нуля | Сложнее выучить pitch/onset |
| Игнорировать Demucs | На clean ok, на stem’ах в deNote — хуже |

### Правильная схема

```text
1) Учим «уметь ноты» на чистых размеченных данных
   GuitarSet / synth  (есть лейблы)

2) Приближаем звук к продакшену (желательно 2-й этап):
   - миксуем гитару с фоном → Demucs → stem
   - лейблы те же (время то же)
   - доучиваем (finetune) на таких stem’ах

3) В deNote: Demucs stem → уже более знакомый домен
```

Итого:

- **Сначала** — датасет с готовой разметкой (GuitarSet).  
- **Потом** — finetune на **Demucs-обработанных** версиях **тех же** (или похожих) размеченных кусков.  
- **Не** «только raw Demucs с YouTube без нот».

## Что от тебя по данным (практично)

### Минимум, чтобы начать

1. Скачать **GuitarSet** (архив с audio + annotation).  
2. Положить в `data/raw/guitarset/` (когда появится скрипт/README — точный путь).  
3. Запустить train-скрипт (когда будет «одна кнопка»).  
4. **Не** размечать свои песни руками на старте.

### Если хочешь «как в deNote» (умнее, второй этап)

1. Есть clean audio + labels (GuitarSet).  
2. Скрипт: clean → (optional mix) → **Demucs** → stem → тот же label.  
3. Finetune на кэше stem+labels.

### Вокал

- Отдельный размеченный vocal-датасет **или** synth + later finetune.  
- В бою: Demucs **vocals** stem → модель.  
- GuitarSet **не** заменяет vocal data.

## Простой UX: «кинул файлы → запустил → учится»

*(Целевая схема; скрипт ещё нужно дописать в коде.)*

### От тебя

1. Положить **аудио + разметку** в папку (не только wav).  
2. Запустить **одну команду**.  
3. Дождаться `runs/.../best.mpk`.

### Папки

```text
denote-ai-model/
  data/
    raw/
      guitarset/          ← ТЫ кладёшь скачанный датасет
    cache/                ← скрипт создаст сам
  runs/
    guitarset/
      best.mpk            ← готовая модель
  scripts/
    train_guitarset.ps1   ← одна кнопка (планируется)
```

### Важно

Одних mp3/wav **недостаточно**. Нужны **правильные ноты** (когда какая нота началась/закончилась).

## Ответы в одну строку

| Вопрос | Ответ |
|--------|--------|
| Где разметка? | В **готовых датасетах** (GuitarSet JAMS, MIDI synth) или делаешь сам |
| Данные важнее кода? | **Да**, для качества почти всегда |
| Учить на выходе Demucs? | **Да как 2-й этап** (stem + **те же лейблы**). **Нет** без разметки / вместо GuitarSet с нуля |
| Что делать сейчас? | Скачать GuitarSet; ждать/делать скрипт train; потом Demucs-domain finetune |

---

## Что не делать

- Кидать в train случайные песни без нотной разметки  
- Ожидать, что «просто mp3» чему-то научит  
- Сразу учить только на full mix без separation (в deNote всё равно stem)  
- Путать smoke-тест (`--smoke`) с настоящим обучением на датасете  

---

## Итог

**От тебя:** положить размеченный датасет (лучше GuitarSet) и потом запустить один скрипт.  
**От кода:** mel, кэш, обучение, чекпоинт.  
**Demucs:** учить «уметь ноты» на clean labels, затем по возможности доучить на stem’ах с **теми же** labels — ты прав насчёт домена, но без разметки stem’ы бесполезны для supervised train.  
**Вокал:** отдельные данные, не GuitarSet.
